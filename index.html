01はじめに

Tarot Draw（以下「本アプリ」）をご利用いただきありがとうございます。本プライバシーポリシーは、iOS・Android アプリ版および Web アプリ版（tarot-draw.naru2.com）のすべてに適用されます。

要点

本アプリは、氏名・メールアドレス・位置情報などの個人情報を一切収集しません。アカウント登録も不要です。

02収集する情報

本アプリが収集・保存する情報は以下の通りです。

情報の種類収集の有無保存場所対象
氏名・メールアドレス等の個人情報収集しない—全版
カメラ・マイク使用しない—全版
GPS 位置情報使用しない（出生地はアプリ内の都市リストから選択）—全版
ホロスコープ用プロファイル（生年月日・出生時刻・出生地）任意で保存（ホロスコープ機能を使った場合のみ）端末内 DataStore アプリ版 / IndexedDB Web版全版
占い履歴（カード・日時・テーマ）保存する端末内 IndexedDB Web版 / 端末内ストレージ アプリ版全版
広告の最終表示時刻・初回起動フラグ保存する端末内（SharedPreferences）アプリ版
Cookie・トラッキングピクセル（広告計測）使用するブラウザ内Web版
クラッシュログ・使用統計（Firebase）自動収集するGoogle のサーバーアプリ版
広告識別子（AdMob）自動収集するGoogle のサーバーアプリ版

Web版ではサービスワーカーによるオフラインキャッシュを使用します。iOS Safari では ITP により、7日間アクセスがない場合に IndexedDB のデータが削除される場合があります。

03情報の利用目的

  • 占い履歴の保存・表示・まとめ送信機能の提供
  • 広告の表示頻度を適切に管理するための記録
  • A8.net アフィリエイト広告のクリック計測
  • Firebase Crashlytics によるクラッシュ解析・アプリ品質改善（アプリ版）
  • Google AdMob による広告配信（アプリ版）
  • ホロスコープ計算（太陽星座・月星座・アセンダント・9 惑星位置）

04第三者への提供

重要

本アプリは、お客様の情報を第三者に販売することは一切ありません。

本アプリは以下の外部サービスを使用しており、サービス提供に必要な情報を各サービスのサーバーに送信します。送信された情報は各サービスのプライバシーポリシーに従って処理されます。

サービス目的対象
Google（Firebase / AdMob）クラッシュ解析・広告配信アプリ版
A8.net（アフィリエイト）広告クリック計測Web版
CloudflareCDN・アクセス解析Web版

Google プライバシーポリシー　／　A8.net プライバシーポリシー

05外部サービスとの連携

「AIに聞く」ボタンを使用した場合に限り、引いたカードの情報と入力した相談内容を外部 AI アプリ（ChatGPT・Gemini・Claude 等）に渡します。

  • この共有はお客様の明示的な操作によってのみ実行されます
  • 本アプリのサーバーを経由しません
  • 渡された情報はお客様が選んだ AI アプリのプライバシーポリシーに従って処理されます
  • 相談内容に個人情報を含める場合はご注意ください
  • 「ホロスコープを同梱する」トグルがオンの場合、生年月日・出生時刻・出生地もテキストに含まれます

06広告・アフィリエイトについて

Web版（tarot-draw.naru2.com）

現在、A8.net を通じたアフィリエイト広告を掲載しています。広告をクリックすると A8.net のトラッキングサーバーを経由して広告主サイトへ遷移します。クリック計測のために 1×1 ピクセルのトラッキング画像が使用されます。将来的に Google AdSense 等のサードパーティ広告を追加する場合は、本ポリシーを更新します。

アプリ版（iOS・Android）

Google AdMob による広告を配信しています。広告識別子（IDFA / GAID）が使用されます。

07通知機能について アプリ版のみ

  • 通知のために個人情報を収集・送信することはありません
  • 通知の配信処理はお客様の端末内でのみ完結します
  • 通知はいつでも端末の設定画面から停止できます

08データの保存場所

  • IndexedDB（ブラウザ内）：占い履歴を端末のブラウザ内に保存します。ブラウザのデータ削除またはサイトデータのクリアにより削除されます。Web版
  • SharedPreferences（端末内）：初回起動フラグ・広告の最終表示時刻を保存します。アンインストールで削除されます。アプリ版
  • DataStore Preferences（端末内）：ホロスコープ用プロファイル（生年月日・出生時刻・出生地）を保存します。アプリ内「プロファイルを削除」ボタンまたはアンインストールで削除されます。アプリ版
  • Google のサーバー：Firebase・AdMob がクラッシュログ・広告識別子を送信します。アプリ版
  • Cloudflare のサーバー：CDN 経由のアクセスログを一時保存します（IP アドレス等）。Web版

09お子様のプライバシー

本アプリは13歳未満のお子様を対象としていません。本アプリは個人情報を一切収集しないため、意図せずお子様の個人情報が収集される可能性はありません。

10本ポリシーの変更

法令の改正・機能追加等に応じて本ポリシーを変更することがあります。変更後のポリシーは本ページに掲載した時点で効力を生じます。重要な変更がある場合はアプリ内またはストアの更新情報でお知らせします。

11免責事項

重要

本アプリのタロット占い結果は、エンターテインメントおよび自己洞察を目的としたものです。医療・法律・財務・人生の重要な判断の根拠とすることはお控えください。

12お問い合わせ・データ削除リクエスト

本アプリで収集または送信されたデータの削除リクエスト、ご質問、不具合報告、機能リクエストは以下のフォームよりお送りください。

1. 端末内データの削除

  • アプリ版本アプリをアンインストールするか、Android の「設定 → アプリ → Tarot Draw → ストレージ → データを消去」で端末内データを完全削除します。
  • Web版ブラウザの「サイト設定 → データを削除」または「履歴とサイトデータの削除」を使用します。
  • アプリ版ホロスコープ用プロファイルは、生年月日入力画面の「プロファイルを削除」ボタンでいつでも個別に削除できます。

2. 広告 ID のリセット Android アプリ版のみ

  • Android の「設定 → Google → 広告」から「広告 ID をリセット」または「広告 ID を削除」を実行します。

3. Google サーバーに保存されたデータの削除依頼

Firebase Crashlytics・Google AdMob が Google のサーバー上に保存しているデータの削除をリクエストする場合は、下記のフォームよりご連絡ください。

お問い合わせ・データ削除リクエストフォーム

https://forms.gle/R3msYE5Qu7Uuida38

お問い合わせの目的を選択してください。データ削除リクエストへの対応には数日〜数週間を要する場合があります。

本アプリは個人を特定できる情報を一切収集していないため、ユーザー個人を識別したデータの削除はそもそも行えない可能性があります。可能な限りの対応をいたします。
